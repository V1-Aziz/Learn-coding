Section 5.2
JSON — JavaScript Object Notation

JSON is the universal language of APIs. Data is always sent and received as JSON strings — you convert them into usable JavaScript objects and back.

Parsing JSON (string → object)
const json = '{"name":"Chicken Taco","price":2.99}'

// Convert string to JS object
const obj = JSON.parse(json)
console.log(obj.name)  // "Chicken Taco"
console.log(obj.price) // 2.99
Stringify + Search
// Convert object back to string
JSON.stringify(obj)
// '{"name":"Chicken Taco",...}'

// Search a JSON array
const recipe = data.find(item =>
  item.name.includes("Chicken")
)
✓
JSON.parse() — converts a string into a usable JavaScript object
✓
JSON.stringify() — converts an object back into a string for display
✓
Searching arrays with .find() to get a specific item
✓
Passing JSON data to EJS templates for rendering

Section 5.3
Axios — Making HTTP Requests

Axios is a library that lets your server talk to external APIs. It handles sending requests and receiving responses using async/await.

Basic GET with async/await
app.get("/", async (req, res) => {
  try {
    const response = await axios.get(
      "https://bored-api.appbrewery.com/random"
    )
    res.render("index.ejs", {
      data: response.data
    })
  } catch (error) {
    res.render("index.ejs", {
      error: error.message
    })
  }
})
With query parameters
// params builds URL automatically:
// /filter?type=social&participants=2
axios.get(URL + "/filter", {
  params: {
    type: req.body.type,
    participants: req.body.participants
  }
})

// Pick a random item from results
const items = response.data
const random = items[
  Math.floor(Math.random() * items.length)
]

Section 5.4
API Authentication — 4 Methods

APIs use authentication to verify who is making a request. Each method sends credentials differently — in the URL, in a header, or encoded in the request.

No Auth
Public APIs — no credentials needed
axios.get(API_URL + "random")
Basic Auth
Username + password encoded in the header
axios.get(URL, {
  auth: {
    username: yourUsername,
    password: yourPassword,
  }
})
API Key
Unique key passed as a query param in the URL
axios.get(URL, {
  params: {
    score: 5,
    apiKey: yourAPIKey,
  }
})
// → /filter?score=5&apiKey=...
Bearer Token
Token sent in the Authorization header
axios.get(URL, {
  headers: {
    Authorization:
      `Bearer ${yourBearerToken}`
  }
})
✓
No Auth — public endpoints, plain axios.get() with no options
✓
Basic Auth — auth: { username, password } option in Axios
✓
API Key — passed as params in the URL query string
✓
Bearer Token — passed in headers as Authorization: Bearer ...

Section 5.5
REST APIs — CRUD Operations

REST APIs use 5 HTTP methods to cover every possible data operation. Together they form CRUD — Create, Read, Update, Delete — the backbone of every web app.

Method Action Axios Call URL Pattern
GET Read data axios.get(url, config) /secrets/42
POST Create new axios.post(url, body, config) /secrets
PUT Replace all fields axios.put(url, body, config) /secrets/42
PATCH Update some fields axios.patch(url, body, config) /secrets/42
DELETE Remove data axios.delete(url, config) /secrets/42
Reusable config — define once, use in every request
// Define once at the top
const config = { headers: { Authorization: `Bearer ${yourBearerToken}` } }

// Reuse everywhere — no repetition
const result = await axios.get(API_URL + "/secrets/" + id, config)
const result = await axios.put(API_URL + "/secrets/" + id, req.body, config)
const result = await axios.delete(API_URL + "/secrets/" + id, config)
✓
PUT replaces the entire record — all fields must be sent
✓
PATCH updates only the fields you send — others stay unchanged
✓
DELETE takes no body — just the ID in the URL
✓
config object stores auth and is reused across all requests
GET POST PUT PATCH DELETE config

Secrets Project — Built from Scratch

A complete web app built with no scaffolding — combining everything from this section into a working project that fetches real data from a live API.

Complete route — fetch & render
app.get("/", async (req, res) => {
  try {
    const result = await axios.get(
      API_URL + "/random"
    )
    res.render("index.ejs", {
      secret: result.data.secret,
      user:   result.data.username
    })
  } catch (error) {
    res.render("index.ejs", {
      error: error.message
    })
  }
})
Key lessons learned
✓

✓

✓

✓

✓
express.static("public") serves CSS and images
