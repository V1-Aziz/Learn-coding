Always read the day's `main.py` file before saving or updating the memory for that day.

**Why:** The file contains the actual code written, which should inform what gets recorded in memory (topics covered, patterns used, etc.).

**How to apply:** When the user says "save this to day X" or "done, save that", read `main.py` first, then write the memory entry based on what's actually in the file.
